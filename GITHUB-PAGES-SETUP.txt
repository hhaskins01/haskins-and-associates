HASKINS AND ASSOCIATES - GITHUB PAGES

Website address:
https://hhaskins01.github.io/haskins-and-associates/

1. Extract all files from this ZIP archive.
2. Open the hhaskins01/haskins-and-associates GitHub repository.
3. Upload the extracted contents to the main branch, ensuring index.html is
   located at the repository root rather than inside an extra folder.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Select the main branch and the / (root) folder, then select Save.
7. Leave Custom domain empty. No custom domain or CNAME file is required.
8. Wait for GitHub Pages to publish the site, then open the address above.

GitHub Pages hosts the static website and live third-party market widgets.
Automatic official Prime/Repo updates, the AI endpoint, and the lead database
require an optional separately deployed Cloudflare Worker.
